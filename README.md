# LaunchAtLogin

Launches a Windows app at login, and respects the user turning it off in Task Manager's Startup apps.

For how to use the package, see [PACKAGE.md](LaunchAtLogin/PACKAGE.md).

## Development

Run `build-and-test.cmd`.

To check that launching at login really works, run the [end-to-end test](LaunchAtLogin.EndToEnd/README.md).
It needs you to log out and back in.
